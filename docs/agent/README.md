# Agent knowledge map

This directory is project knowledge for Codex, not a second copy of the project's documentation.

When this kit is installed into a real project, run the `bootstrap-project` skill. It should link to authoritative existing docs and create only the missing maps needed for agent legibility.

Expected maps when useful:

- `architecture.md` — domains, layers, boundaries, entry points.
- `product.md` — evidenced product/domain rules.
- `workflows.md` — important end-to-end flows and state transitions.
- `quality.md` — validation commands, quality gates, known gaps.

Unknown facts stay unknown. Prefer executable checks over prose rules.
